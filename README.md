# Girish Lade — Portfolio (Indian Theme)

A single-page personal portfolio website for Girish Lade with an Indian-inspired visual theme — deep indigo night background, gold/saffron/peacock-green accents, and classic serif typography.

## Features

- Hero section with developer/designer/AI-innovator positioning
- About, skills, projects, and contact sections in a smooth-scroll single page
- Indian-theme design language: saffron-gold gradients, peacock accents, Tinos serif display type
- Responsive layout built on Tailwind CSS via CDN
- Font Awesome iconography, Google Fonts (Inter + Tinos)

## Tech Stack

- Plain HTML5 + CSS3 (no build step)
- Tailwind CSS (CDN)
- Google Fonts, Font Awesome (CDN)

## Quick Start

No build needed — open `index.html` in any modern browser:

```bash
git clone https://github.com/girishlade111/Girish-Lade---Portfolio-Indian-Theme-.git
cd Girish-Lade---Portfolio-Indian-Theme-
open index.html   # or just double-click the file
```

Or serve locally:

```bash
npx serve .
```

## Deploy

This is a static site — it deploys anywhere static hosting works. It is published via GitHub Pages; any static host (Cloudflare Pages, Netlify, Vercel) works by pointing at the repo root.
